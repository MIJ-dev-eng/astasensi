# FireSensi — Free Fire Sensitivity Generator

A static HTML/CSS/JavaScript starter website. No server, paid API, or account is required.

## Run locally
Open `index.html` in a modern browser. For best clipboard support, use a local development server such as VS Code Live Server.

## Deploy free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important accuracy note
The built-in device profiles and algorithm produce heuristic starting suggestions. They are not validated or guaranteed optimal for each exact phone. Do not market these values as tested until you have collected real device testing results. Sensitivity scales can change between game versions; update the displayed range and algorithm if needed.
